  UNKNOWN / not listed    → reason freely using NIST PQC standards

Rules:
1. Output ONLY valid JSON — no markdown, no prose before or after.
2. Preserve the original code's logic, variable names, and structure.
3. If the finding is in a non-Python file, set strategy to "manual_only".

5. All dependency names in new_dependencies must be real, installable pip packages.

  "new_dependencies": ["<pip-package>", ...],

    "key_size": "<recommended key size or parameter set>",
    "api_note": "<any API surface difference the migrator must handle>",
    "caveat": "<any important warning, or empty string>"
  }
}
