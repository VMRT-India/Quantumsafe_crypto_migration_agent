# Session Screenshots

This folder collects AI/development session screenshots from all four team members.

## Structure

```
session_screenshots/
├── Maruti/     ← Maruti's session screenshots
├── Samik/      ← Samik's session screenshots
├── Navya/      ← Navya's session screenshots
└── Palak/      ← Palak's session screenshots
```

## Rules

1. **Each developer drops their screenshots into their own named folder** on their
   personal branch (`changes-Maruti`, `changes-Samik`, `changes-Navya`, `changes-Palak`).

2. **Name your files clearly** so reviewers and judges can follow the session sequence:
   ```
   YYYY-MM-DD_HH-MM_<brief-description>.png
   # Examples:
   2024-08-30_14-30_ingestion-module-scan-result.png
   2024-08-30_16-00_rsa-migration-before-after.png
   ```

3. **When branches are merged into `main`**, all four folders come together
   automatically — the competition can see every team member's session work
   in one place.

4. **Do not add screenshots to another person's folder.** Each folder belongs to
   that developer.

5. **No credentials or sensitive data** should appear in screenshots. Blur or
   crop anything that looks like an API key, project ID, or password before saving.

## Why this folder exists

The IBM Dev Day Hackathon requires evidence of each team member's individual
contribution. Screenshots of working sessions, terminal output, and tool results
demonstrate active development by each person.
