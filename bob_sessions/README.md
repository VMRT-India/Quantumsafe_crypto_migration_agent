# Bob Sessions

This folder collects AI (Bob) session screenshots from all four team members,
used as evidence of individual contribution for the IBM Dev Day Hackathon.

## Structure

```
bob_sessions/
├── Maruti/     ← Maruti's Bob session screenshots  (branch: changes-Maruti)
├── Samik/      ← Samik's Bob session screenshots   (branch: changes-Samik)
├── Navya/      ← Navya's Bob session screenshots   (branch: changes-Navya)
└── Palak/      ← Palak's Bob session screenshots   (branch: changes-Palak)
```

## Rules

1. **Each developer adds screenshots to their own named folder**, committed on
   their personal branch (`changes-Maruti`, `changes-Samik`, `changes-Navya`,
   `changes-Palak`) first — then the branch is merged into `main`.

2. **Name files clearly** so judges can follow the session sequence:
   ```
   YYYY-MM-DD_HH-MM_<brief-description>.png
   # Examples:
   2024-08-30_14-30_ingestion-module-scan-result.png
   2024-08-30_16-00_rsa-migration-before-after.png
   ```

3. **Do not add screenshots to another person's folder.**

4. **No credentials or sensitive data in screenshots.** Blur or crop any
   API key, project ID, or password before saving.

## Why this folder exists

The IBM Dev Day Hackathon requires evidence of each team member's individual
contribution. Screenshots of working Bob sessions, terminal output, and tool
results demonstrate active development by each person.
